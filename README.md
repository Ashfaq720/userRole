## 🧩 Project Overview
This repository demonstrates a **User Role Management System** in Laravel.  
It includes features like:

- Role-based authentication (Admin, Editor, User, etc.)  
- Access control using middleware  
- User registration, login, and profile management  
- Clean and testable code structure  
- Example unit and feature tests
